# Repository working instructions

This repository is part of the three-repo Blustone revival split. The user authorized pushes and release publication on 2026-10-10. Publish only reviewed project content; retain the original workspace and ignored private archives. Preserve the original workspace and all originals/private captures.

- Server owns runnable API code, accepted runtime data/resources and launch configuration.
- Instrumented owns diagnostic client source, native patches, collector and observation/control tooling.

local/ and var/ are private/large preservation storage and must stay ignored. Never publish account tokens, device cookies, saves, raw private telemetry or signing keys. See the local migration report and preserved original workspace guidance for detailed history.
